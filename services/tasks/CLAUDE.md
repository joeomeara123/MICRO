# Task Service

This folder contains the service layer for all task database operations.

## Files

- `task-service.ts` - Core service functions
- `index.ts` - Public exports

## Pattern

All service functions return `TaskServiceResult<T>`:
```typescript
interface TaskServiceResult<T> {
  data: T | null;
  error: Error | null;
}
```

## Available Functions

- `fetchUserTasks(userId, options?)` - Fetch tasks with filtering
- `updateTaskStatus(taskId, status)` - Update task status
- `snoozeTask(taskId, until)` - Snooze a task
- `createTask(task)` - Create a new task
- `deleteTask(taskId)` - Soft delete a task

## Usage

```typescript
import { fetchUserTasks, updateTaskStatus } from '@/services/tasks';

// Fetch pending tasks
const { data, error } = await fetchUserTasks(userId, { status: 'pending' });

// Approve a task
await updateTaskStatus(taskId, 'approved');
```

## Notes

- All functions have console logging for debugging
- The Supabase client is currently untyped (US-006/US-007 pending)
- Response data is cast to Task type for components
